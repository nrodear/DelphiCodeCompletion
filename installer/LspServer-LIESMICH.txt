dpcc.LspServer.exe - LSP server of dpcc (Delphi Pascal Code Completion)

What it is: dpcc as a standalone language server (LSP over stdin/stdout). In Delphi 12 and 13 it takes the place
of DelphiLSP.exe; the IDE keeps its own windows, the answers come from dpcc.
Contents: win32\dpcc.LspServer.exe (32 bit), win64\dpcc.LspServer.exe (64 bit), this file.
Where to put it: place one EXE next to the plugin (folder of dpcc.Plugin290.bpl or dpcc.Plugin370.bpl) or extract
the folders win64 and win32 to %LOCALAPPDATA%\Programs\dpcc\server. On 64-bit Windows use the 64-bit EXE; the
32-bit IDE starts it.
Turning it on: in Delphi, Tools > Options > Third Party > dpcc, select the mode "Server", OK. Coming from the mode
Plugin this takes effect after restarting Delphi, coming from "Off" the next time a project group is opened.
Error Insight stays empty. The 64-bit IDE of Delphi 13 is not supported.
Version: dpcc.LspServer.exe --version
Storage: %LOCALAPPDATA%\dpcc.LspServer (other location: --cache-root <folder> or DPCC_LSPSERVER_CACHE_ROOT).
